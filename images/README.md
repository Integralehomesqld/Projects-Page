# Images

Drop your photos straight into this folder using these exact filenames, and they'll appear on the live page automatically — no other changes needed.

| Filename                    | Used for                                      | Suggested size |
|------------------------------|------------------------------------------------|-----------------|
| `hero.jpg`                   | Top banner photo                                | ~1600×800px, landscape |
| `retirement-village.jpg`     | Village Green Estate card                       | ~800×500px |
| `lakeside-terraces.jpg`      | Lakeside Terraces card                          | ~800×500px |
| `birtinya-row.jpg`           | Birtinya Row card                               | ~800×500px |
| `nirimba-duplex.jpg`         | Nirimba Duplex Program card                     | ~800×500px |
| `moffat-duplex.jpg`          | Moffat DKR Program card                         | ~800×500px |
| `aura-retirement.jpg`        | Aura Retirement Precinct card                   | ~800×500px |
| `capability.jpg`             | "Why partner with us" section photo             | ~900×700px, portrait-ish |

Notes:
- File names are case-sensitive and must match exactly (all lowercase, `.jpg`).
- If you'd rather use `.png` or `.webp`, that's fine too — just tell Claude and it'll update the file extension referenced in `index.html` to match.
- Until a file is added, that spot on the page just shows the dashed placeholder — nothing breaks.
